Network / app sources

Any PulseAudio client on your LAN (set PULSE_SERVER=pi.local:4713) appears here automatically as an input. RTP receivers let you pull RTP audio from a phone over Wi-Fi.

Bluetooth devices

Codec - the phone picks this; BlueZ has no API to change it

Bluetooth test tone

idle

Open this page on your phone and press play — the tone streams to the Pi over Bluetooth, so the Pi can measure what the link actually delivers. The segments are self-identifying: each starts with N beeps (N = segment number) so a capture can be matched up exactly.

Web output

Sends the mixed audio to this tab instead of a speaker or headset. Playback starts on click because browsers require a gesture. Keep this tab open and unmuted — latency is about 200 ms.
